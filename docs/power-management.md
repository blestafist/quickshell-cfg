# Питание: Artix + dinit + elogind

Меню вызывает `loginctl poweroff/reboot`; сон — `scripts/lockctl lock-and-suspend`.
`/usr/local/bin/poweroff` и `reboot` передают запрос elogind без sudo.
Штатная polkit-политика разрешает эти действия активному локальному пользователю.
Дополнительные группы и NOPASSWD не нужны; запросы с чужими сеансами или
блокирующими inhibitors могут быть отклонены — это намеренно не обходится.

## Сеанс niri

- `Super+Alt+L`: блокировка; `Super+S`: меню питания.
- Кнопка питания: меню (niri перехватывает её у elogind).
- Кнопка сна: блокировка с подтверждением композитора, затем сон.
- Автоблокировки и выключения мониторов по таймеру нет.
- Для блокировки использовать сочетание клавиш или `scripts/lockctl lock`.
  Обработчика `loginctl lock-session` нет.
- Внешний сон (включая прямой `loginctl suspend` и крышку) отменяется,
  если экран ещё не заблокирован. Для блокировки с последующим сном
  использовать меню или `scripts/lockctl lock-and-suspend`.

## Системные настройки

- `/etc/elogind/logind.conf.d/90-desktop-power.conf`: кнопки, крышка, 25 секунд
  для delay-inhibitors; без автоматического сна по IdleHint.
- `/etc/elogind/sleep.conf.d/90-desktop-sleep.conf`: сон разрешён, гибернация
  отключена (swap только zram), разрешена отмена сна системным hook.
- `/etc/elogind/system-sleep/10-require-session-lock`: финальная проверка IPC
  блокировщика от UID 1000 для графических сеансов. При отсутствии защищённого
  состояния печатает ERROR и отменяет сон. Другие графические пользователи
  требуют отдельной настройки. Обычные tty не требуют Wayland-блокировщика.
- Существующий NVIDIA hook и kernel suspend notifiers не изменены.

Прямая команда `sudo /usr/bin/poweroff` обходит elogind. Для обычной работы
использовать `poweroff` или `loginctl poweroff`; не применять `--force`.
Delay-inhibitor ограничен по времени; финальная проверка блокировки снижает
риск сна без защиты, но не доказывает отсутствие всех гонок при внешнем сне.
Предпочтительный путь — `lockctl lock-and-suspend`, где владелец блокировки
не разрешает аутентификацию во время запроса сна.

Резервные копии прежних root-файлов: `/var/backups/desktop-power-20261114/`.
Конфигурация elogind перечитана без перезапуска службы.
Реальное выключение, сон и ввод пароля в живом блокировщике автоматически
не проверялись, чтобы не прерывать рабочий сеанс.
