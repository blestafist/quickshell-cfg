# QuickShell + Hyprland Plan

## Concept

Minimalist shell with only essential status permanently visible. All actions open contextually and quickly. The primary display, `DP-1`, is the working center with one panel and a bottom-sheet launcher. `HDMI-A-1` remains visually clean, without a permanent panel.

The first release does not attempt to replace every utility at once. It delivers a polished bar and launcher, a shared theme/runtime foundation, and correct Hyprland integration. Control Center, notes, calculator, and AI are added later as independent modules.

## Fixed Decisions

- QuickShell `0.3.1`, Hyprland `0.56.2`.
- Primary monitor: `DP-1`, `2560x1440@180`.
- Secondary monitor: `HDMI-A-1`, `1920x1080@60`, rotated vertically.
- One bar on `DP-1` only.
- Visual style: warm minimalism, matte surfaces, a soft accent extracted from the current wallpaper, and no excessive glass or blur.
- Launcher: a bottom sheet inspired by Caelestia, with a distinct visual language and interaction model.
- Launcher hotkey: `Super + R`.
- Launcher v1: XDG desktop applications and system/user commands.
- EndeavourOS icon: left click opens the launcher; right click opens the future configurator.
- Bar: EndeavourOS, CPU/RAM/GPU, clock, network, audio, keyboard layout, and power button.
- Workspaces are not shown on the bar.
- Wallpaper engine: `swww`.
- Theme generation: `matugen`.
- Configurator: a reliable config file and reload flow first, followed by a GUI over the same format.
- AI: not in v1. Architecture will reserve a dedicated provider module.

## Architecture

```text
~/.config/quickshell/
  shell.qml                     # QuickShell entry point

  config/
    ShellConfig.qml             # User interface preferences
    MachineConfig.qml           # DP-1, HDMI-A-1, and host-specific settings
    Actions.qml                 # Registered launcher, power, and settings actions

  theme/
    Theme.qml                   # Semantic colors, spacing, and surfaces
    Typography.qml              # Font families and type scale
    Motion.qml                  # Animation durations and easing curves
    generated/
      Colors.qml                # Generated by Matugen; never edit manually

  services/
    Hyprland.qml                # Keyboard layout, monitor and window state
    Audio.qml                   # PipeWire/WirePlumber volume and devices
    Network.qml                 # NetworkManager network and VPN state
    Resources.qml               # CPU, RAM, GPU, VRAM, and temperature
    Wallpaper.qml               # swww + Matugen + theme reload integration
    Applications.qml            # XDG desktop application index and launching
    Session.qml                 # Lock, logout, suspend, reboot, shutdown
    Notifications.qml           # Future notification service
    Ai.qml                      # Future AI provider interface

  components/
    Surface.qml                 # Shared matte card surface
    IconButton.qml              # Standard click target
    StatusChip.qml              # Small status item for the bar
    Popover.qml                 # Reusable popover layer
    AnimatedReveal.qml          # Shared visibility transitions
    ShortcutHint.qml            # Keyboard hints

  modules/
    bar/
      Bar.qml
      DistroButton.qml
      ResourceMonitor.qml
      Clock.qml
      NetworkIndicator.qml
      AudioIndicator.qml
      KeyboardLayout.qml
      PowerButton.qml

    launcher/
      Launcher.qml
      SearchField.qml
      ResultList.qml
      ApplicationResult.qml
      CommandResult.qml
      LauncherController.qml

    control-center/             # After v1
    calculator/                 # After v1
    notes/                      # After v1
    wallpaper/                  # After v1
    settings/                   # GUI configurator after v1
    ai/                         # Separate release
    osd/                        # Volume, brightness, and layout feedback
    notifications/              # Notification replacement
    power-menu/                 # Power button actions and confirmations

  scripts/
    update-theme.sh             # swww -> matugen -> QuickShell reload
    gpu-stats.sh                # Fallback when direct GPU data is unavailable
    shellctl                    # Reload and diagnostics CLI

  assets/
    icons/
    wallpapers/
```

## Visual Language

- Shell surfaces must not compete with wallpapers: use dark or gently tinted matte surfaces with high text contrast.
- Use one accent color and softer variants generated by Matugen.
- Do not make the bar a row of identical chips. Group content by purpose:
  - Left: EndeavourOS button.
  - Center: clock.
  - Right: resources, network, audio, keyboard layout, and power.
- CPU/RAM/GPU appear as one compact widget with icons and values. A click opens a popover with percentages, temperature, and memory details.
- The launcher rises from the bottom edge of `DP-1` with a soft spring-like transition. It dims only the primary monitor and takes keyboard focus.
- Search results show an icon, name, short command/description, and action hint. Avoid category clutter in v1.

## Implementation Plan

### 1. Prepare Integration

- Add QuickShell startup to Hyprland.
- Replace Waybar with QuickShell, Rofi with the QuickShell launcher, and Wlogout with a temporary session flow in the shell.
- Rebind `Super + R` from `rofi -show drun` to the QuickShell launcher IPC command.
- Keep `hyprlock` as the real lock screen. QuickShell must not take responsibility for critical lock-screen security.
- Remove old Waybar and Rofi layer rules only after the new shell is verified.

### 2. Create Runtime and Configuration

- Create `shell.qml` and the modular directory structure.
- Define `MachineConfig.qml` with `DP-1` as the primary output and `HDMI-A-1` as the secondary output.
- Put bar dimensions, launcher placement, enabled modules, clock format, commands, and animation preferences in `ShellConfig.qml`.
- Add `shellctl reload` and a diagnostics command that checks dependencies.

### 3. Implement Theme Generation

- Continue using Matugen and add a QML `Colors.qml` template.
- Create a wallpaper/theme update script: set the wallpaper with `swww`, run Matugen, generate palettes for QML and Hyprland, then reload QuickShell.
- Replace the hardcoded palette in `~/.config/hypr/hyprland/colors.conf` with generated Matugen output.
- Use semantic values such as `surface`, `surfaceRaised`, `textPrimary`, `accent`, and `danger`, rather than raw hex colors in components.

### 4. Build Bar v1

- Create an exclusive bar layer for `DP-1`; `HDMI-A-1` receives no permanent bar.
- Add the EndeavourOS button: left click opens launcher; right click opens future settings.
- Implement the resources service: CPU, RAM, GPU, VRAM, and temperature, with a graceful fallback if GPU metrics are unavailable.
- Integrate NetworkManager for network status.
- Integrate PipeWire/WirePlumber for volume, mute, and output-device selection.
- Read the current keyboard layout from Hyprland.
- Add the clock and power button.
- Add detail popovers for resources, network, and audio without expanding the bar itself.

### 5. Build Launcher v1

- Open and close it using QuickShell IPC, triggered by `Super + R`.
- Display a bottom sheet on `DP-1`; take focus on open; close on `Escape`; execute the selected result on `Enter`.
- Index desktop entries from XDG directories and respect `NoDisplay`, `Hidden`, `Exec`, and `Terminal` fields.
- Add an action registry with terminal, browser, file manager, lock, shell reload, wallpaper picker, and power menu commands.
- Search by name, keywords, and commands with sensible ranking.
- Do not add calculator, notes, files, or AI search providers in this phase. Make the registry extensible so they can be added without rewriting the launcher.

### 6. Verify the Replacement

- Ensure Waybar, Rofi, and QuickShell do not run together at login.
- Check launcher behavior in both keyboard layouts.
- Check network, audio, and GPU fallback states.
- Check both monitors, including the rotated `HDMI-A-1`.
- Check QuickShell reload and live theme refresh without restarting Hyprland.

## Later Releases

### Control Center

- A right-side panel with audio, network, Bluetooth, media, brightness when available, quick toggles, and power actions.
- Open it by clicking the status group and with a dedicated hotkey.

### OSD and Notifications

- Visual OSD for volume, mute, keyboard layout, and brightness.
- A single QuickShell notification daemon with history and Do Not Disturb.

### Calculator and Notes

- A launcher calculator provider, for example `= 15% of 240`, with copyable results and no external window.
- Fast local Markdown notes under `~/.local/share/quickshell/notes/`, including search and pinned notes.
- Notes remain independent from Obsidian, with an optional action to open a note in Obsidian.

### Wallpaper Picker

- A visual picker with folders, previews, and per-monitor wallpaper support.
- Atomic `swww`, Matugen, and shell theme updates.
- Recent wallpaper history and rollback.

### Configurator

- Keep `ShellConfig.qml` as the single source of truth initially.
- Build a settings UI for bar placement, modules, clock format, animations, wallpaper, hotkeys, and launcher commands.
- Validate before saving, keep a backup, and offer reload.
- The GUI must edit user parameters only, never QuickShell modules directly.

### AI Assistant

- Add it as a separate panel or launcher mode, never as a permanent widget.
- Define an interface for local Ollama or a cloud API through a local proxy.
- Store secrets only in environment variables or systemd credentials, never in QML or `~/.config/quickshell`.
- First AI release: chat, copy output, and explicitly confirmed shell actions. Never execute a model-generated command automatically.

## Existing Foundation

- The current Rofi configuration already uses a bottom launcher and Matugen colors. The new launcher keeps the familiar geometry while becoming native QuickShell UI.
- The current Waybar configuration contains the target status set: CPU, RAM, GPU, network, audio, keyboard layout, clock, and power. Reimplement it using QuickShell services rather than copying polling scripts.
- The current `hyprlock` stays the dedicated lock screen, with colors and typography eventually connected to the common theme pipeline.
- The current Hyprland configuration already defines `DP-1` and `HDMI-A-1`. V1 only needs careful changes to startup, `Super + R`, and layer rules.
